# Portrait photos

Put your photos here. Keep these exact file names so the site finds them automatically:

| File name | Where it shows |
|---|---|
| `01-hero-portrait.jpg` | Hero (top of the page) |
| `02-about-portrait.jpg` | About Me |
| `03-why-me-portrait.jpg` | Why Choose Me |
| `04-contact-portrait.jpg` | Contact |

- To replace a photo, upload the new one with the same name. It overwrites the old one.
- Use portrait orientation (taller than wide), JPG or PNG. Bigger is better, for example
  the phone original. The site compresses photos automatically.
- Don't put photos in `public/`, because they won't be optimised there.
